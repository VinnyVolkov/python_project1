# Sales Data Analysis with Python

## Overview

This project demonstrates a complete data analysis workflow using Python. The dataset was cleaned, transformed, explored, and visualized to identify sales trends and generate business insights.

## Objectives

- Clean and prepare raw data
- Merge multiple datasets
- Perform Exploratory Data Analysis (EDA)
- Analyze sales performance across countries, regions, and product categories
- Identify seasonal trends and business opportunities
- Create visualizations to communicate insights

## Tools & Technologies

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook (Google Colab)

## Project Workflow

- Imported and merged multiple datasets
- Cleaned missing values and corrected data types
- Removed inconsistencies and prepared data for analysis
- Performed exploratory data analysis (EDA)
- Created charts and visualizations
- Generated business insights and recommendations

## Key Analysis

- Sales trends over time
- Revenue and profit analysis
- Top-performing countries and regions
- Product category performance
- Seasonality analysis
- Business recommendations based on data

## Skills Demonstrated

- Business Analysis
- Statistical Analysis
